# 08 — 选路器与状态机

**What to build:** 负载均衡核心：每次请求在健康上游密钥中选「有效剩余额度最多」者（平手随机，数据来自 05 的簿记）；错误驱动的状态机——429→立即换 key 重试本请求 + 该 key 冷却 60 秒（到期自动恢复）；432/433→标记耗尽至计费周期重置日；401→禁用并产生看板告警；5xx→换 key 重试；400→透传不重试；全部 key 不可用时向调用方返回明确错误。

**Blocked by:** 05 — 额度簿记；07 — MCP 端点 + tavily_search 直转

**Status:** ready-for-agent

- [ ] 两个 key 剩余额度不同时，请求落到额度多者；平手时随机分布
- [ ] 429：本请求被换 key 重试成功，原 key 冷却期内不再被选中，冷却结束自动恢复
- [ ] 432/433：key 被标记耗尽，直到重置日不再被选中
- [ ] 401：key 被禁用并产生告警
- [ ] 5xx：换 key 重试
- [ ] 全部 key 不可用时调用方收到明确错误而非挂起
- [ ] 测试：mock 上游按脚本返回各错误码，断言转移/冷却/耗尽/禁用
